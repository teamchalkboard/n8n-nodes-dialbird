# Changelog

## 0.1.0

- Dialbird Trigger: New Incoming Message, Outgoing Message Delivered, Incoming Call Completed, Outgoing Call Completed. Subscribes and unsubscribes automatically and checks Dialbird's signature on every event.
- Dialbird: Contact → Create, Contact → Update, Message → Send.
- Two ways to connect: Dialbird API credential (API key, any n8n) and Dialbird OAuth2 API credential ("Sign In With Dialbird", n8n Cloud).
